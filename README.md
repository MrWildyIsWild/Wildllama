## Wildllama

A small local AI UI I started building after finishing some of my other projects.

What began as me experimenting for a few days slowly turned into something I genuinely enjoyed using, so I thought I’d share it here too.

Wildllama runs locally with Ollama and focuses on keeping things simple, smooth, and comfortable to use. You can chat with models, upload files, switch themes, revisit conversations, and just interact with local AI in a way that feels a little more personal.


## A few things it can do

* Stream responses in real time
* Save conversations automatically
* Upload images, PDFs, and text/code files
* Light & dark themes
* Drag & drop support
* Simple autocomplete while typing (plz don't judge it)
* Copy or download responses
* Clean and lightweight interface


## Getting started

Make sure Ollama is running first:
if you just type ollama in your terminal, you should see ollama stuff ;-;

Then start Wildllama:
open the terminal where you downloaded the file and run python3 wildllama.py

Open:
http://localhost:8080 <-- very hard to right click the link u get in the terminal and open it ._.
